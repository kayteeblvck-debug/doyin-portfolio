# Doyin — Portfolio

Personal portfolio site. Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · TypeScript, deployed on Netlify.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

| Command             | Description               |
| ------------------- | ------------------------- |
| `npm run dev`       | Start the dev server      |
| `npm run build`     | Production build          |
| `npm run start`     | Serve the production build |
| `npm run typecheck` | Type-check with `tsc`     |
